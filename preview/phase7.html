Phase 7: Edge cases and integration

The check was reviewed for clumsy clicks and for starting again. Five kinds of learner were also scored, to be sure the result page still matches the scoring rules.

What to try in the app

  • Choose an answer and click Next twice quickly. You should move only one question forward.
  • On a question, click Start over. You should be back at question 1, with no answers kept.
  • Finish the check, then click Take the check again. Same fresh start.
  • Refresh the page in the middle. The welcome page comes back. Nothing is saved in the browser.

Five learners the tests score

  • Strong: one small slip. Ready to book.
  • Weak: only two answers right. Not yet.
  • Weak only in grammar: Almost there.
  • Weak only in reading: Almost there.
  • Average, about 60% in each skill: Almost there.
